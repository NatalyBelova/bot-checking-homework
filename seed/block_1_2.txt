Блок 1–2: DevTools, API (Swagger, Postman), Charles Proxy. Ученик присылает все скриншоты блока одной отправкой.

Принимать, если по каждой теме есть скриншот, на котором видно выполненное задание:

DevTools
- Elements: текст на странице изменён через DOM (например, заголовок статьи Википедии заменён своим текстом), видна изменённая страница и выделенный элемент в панели Elements.
- Application → Cookies: найдена cookie через фильтр (видны имя и значение cookie).
- Network: выполнено действие на сайте (например, поиск товара), выбран XHR/Fetch-запрос, открыта вкладка Payload, в ней виден параметр с введённым значением.
- Network → Preview/Response: виден ответ этого запроса в развёрнутом виде.

API
- Swagger: выполнен запрос (Execute), видны Request URL, код ответа 200 и тело ответа (Response body).
- Postman: создан запрос (например, POST на создание покемона), во вкладке Scripts (Post-response) написаны тесты минимум на код ответа и время ответа, во вкладке Test Results тесты в статусе PASSED. Видна коллекция с запросами.
- Kibana (если входит в задание по API): найден свой запрос по trace.id, видны спаны с operationName и кодом ответа.

Charles Proxy
- Перехвачен запрос к API (например, POST /api/v1/Books), тело запроса изменено так, что сервер вернул ошибку валидации (400 Bad Request) — видны изменённое тело и ответ с ошибкой.
- Настроено правило Rewrite (Tools → Rewrite): видны включённое правило, Location (хост/путь) и действие замены (Body: старое значение → новое), а также запрос, в котором подмена сработала.

Возвращать на доработку, если:
- нет скриншотов по какой-то теме блока (DevTools, Swagger, Postman, Charles);
- на скриншоте не виден результат: не видно кода ответа, тела ответа, Payload, PASSED в тестах, сработавшей подмены;
- в Postman нет тестов или тесты упали (FAILED);
- в Charles не видно изменённого запроса или правила Rewrite;
- скриншот нечитаемый (размыт, обрезан так, что не видно ключевых данных).

Неважно: какой именно сайт, товар, id, текст подмены или значения в теле запроса использованы; тема оформления; порядок скриншотов; Windows/Mac; формулировки в названиях тестов.
Частые ошибки: присылают Postman без вкладки Test Results; в Network скриншот без открытого Payload; в Charles — только список запросов без изменённого тела.
